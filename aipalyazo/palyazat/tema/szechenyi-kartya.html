Széchenyi Kártya Program hitelei

A Széchenyi Kártya Program kamattámogatott, kezességgel biztosított hiteleit a KAVOSZ ügyintézőinél, a partnerbankokon keresztül lehet igényelni. Jelenleg 8 nyitott felhívás tartozik ide; a lista naponta frissül hivatalos forrásokból (utoljára: 2026-09-28).

  • Agrár Széchenyi Beruházási Hitel MAX+
    KAVOSZ / Széchenyi Kártya Program · 1 M – 750 M Ft (bankonként eltérő felső határ) · folyamatos
  • Agrár Széchenyi Kártya MAX+
    KAVOSZ Zrt. / Széchenyi Kártya Program (partnerbankok) · 0,5–200 M Ft folyószámlahitel (fiatal gazdának max 25 M Ft), 1–3 év · folyamatos
  • Széchenyi Beruházási Hitel MAX+
    KAVOSZ / Széchenyi Kártya Program · 1–750 M Ft · folyamatos
  • Széchenyi Kártya Folyószámlahitel MAX+
    KAVOSZ / Széchenyi Kártya Program · max. 250 M Ft · folyamatos
  • Széchenyi Likviditási Hitel MAX+
    KAVOSZ / Széchenyi Kártya Program · max. 250 M Ft · folyamatos
  • Széchenyi Lízing MAX+
    KAVOSZ / Széchenyi Kártya Program · 1–500 M Ft · folyamatos
  • Széchenyi Mikrohitel MAX+
    KAVOSZ / Széchenyi Kártya Program · 1–150 M Ft (induló vállalkozásnak max. 100 M Ft) · folyamatos
  • Széchenyi Turisztikai Kártya MAX+
    KAVOSZ / Széchenyi Kártya Program · 1–250 M Ft · folyamatos
