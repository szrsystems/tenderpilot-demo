the HTML files.

## Apply all at once (Management API)

1. Create a personal access token: supabase.com → Account → Access Tokens.
2. From the repo root:

```
SUPABASE_ACCESS_TOKEN='sbp_...' sh -c 'curl -sS -X PATCH "https://api.supabase.com/v1/projects/kacnvchwfwvpkkyhyupb/config/auth" -H "Authorization: Bearer $SUPABASE_ACCESS_TOKEN" -H "Content-Type: application/json" --data @supabase/email-templates/auth-config.json -o /dev/null -w "%{http_code}\n"'
```

`200` = applied. Delete the token afterwards if you don't need it.

## Or by hand

Dashboard → Authentication → Emails → pick the template → paste the file's
contents into the body, set the subject, Save.

Inline CSS only (Gmail/Outlook strip `<style>`), no images (often blocked).
